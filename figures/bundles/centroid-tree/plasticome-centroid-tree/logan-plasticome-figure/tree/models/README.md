# Substitution models not shipped with IQ-TREE

`3DI` is the 3Di structural alphabet rate matrix of Puente-Lelievre et al.
(Tertiary-interaction characters enable fast, model-based structural
phylogenetics beyond the twilight zone, bioRxiv 2023.12.12.571181), in the
PAML format IQ-TREE reads.

Source: github.com/nmatzke/3diphy,
`3DI_substmat/3DI_transition_matrices_for_IQtree/3DI`, commit c6e1e6c
(2023-12-11). Fetched 2026-10-01, unmodified.
