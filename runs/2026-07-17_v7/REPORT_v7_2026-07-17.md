# PETadex v7 — Results (flat 490-node partition, collapsed/renumbered PAZy)

Re-runs the [[PETadex v2 — Component Assignment Workflow]] Steps 0–3 on the **collapsed,
renumbered** PAZy TSV (delivered as `data/cleaned_pazy_collapsed.tsv`, renamed to
`data/cleaned_pazy_final.tsv` during this run and snapshotted into `v7/`). Same paper-faithful
method as v4/v5/v6: usearch v11.0.667 `-allpairs_local`, permissive search + `≥30% aaid AND
e<1e−5` post-filter, single-linkage components, both FASTA orientations. Flat de-novo, no v1 anchor.

## What changed vs v6

| | v6 (`cleaned_pazy_final.tsv`, 16:09) | v7 (collapsed/renumbered, 17:21) |
|---|---|---|
| Source rows | 500 (8 multi-id via `;`) | **491** (exact-dup rows collapsed) |
| `identifier` scheme | `PL<n>` | **plain sequential integers `1…491`** |
| Nodes (md5-unique) | 489 | **490** (+1) |
| Remaining exact-dup rows | 0 | 1 pair (id **140 = 141** → 1 node) |

The collapsed file **renumbers** every row to a plain integer identifier (no `PL` prefix, no
`;`-joined multi-id rows) and folds exact-duplicate rows into single identifiers. Node identity is
unchanged — it is still the md5 of the frozen `normalize()` (letters only, uppercased) — so the
canonical component label is now the integer `identifier` (v6 used the `PL<n>`).

**The one biological change:** v7 carries **490 unique sequences vs v6's 489**. The extra node is
**id 422 (`TEP037`, 259 aa)** — a sequence added to the PAZy set after the v6 snapshot. It is not a
collapse artifact; the collapse itself neither added nor dropped any distinct sequence.

## The partition is v6 + one absorbed node

Md5-keyed comparison against v6: the two partitions are **identical on the 489 shared sequences**.
The single new node (`TEP037`) joins **C001**, the α/β-hydrolase megacomponent, adding no edges that
change any other component. So v7 reproduces v6's clustering exactly and grows the dominant
component by one (287 vs 286). Component **IDs are re-lettered** vs v6 (canonical order now follows
the renumbered integer identifiers), but the clusters themselves are unchanged.
