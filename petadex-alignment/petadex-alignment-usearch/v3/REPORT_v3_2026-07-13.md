# Component Assignment — `pazy-260701_cleaned.csv` (v3, 2026-07-13)

Assigns a **component** to every sequence in `data/pazy-260701_cleaned.csv` using the
paper-faithful method from [[05 — Component Assignment v2 — Experiment Outline]] /
[[07 — Component Assignment v2 — Results & Method Corrections]] — a connected component in
the all-vs-all amino-acid similarity graph (≥30% aaid AND e<1e−5), anchored on the validated
**v1 42-component reference**.

## Method (as run)

- **Node set = 476**: 205 v1 reference nodes (carry `v1_component`/`cath`, reconstructed from
  `v2/canonical_nodes.tsv` + `v2/canonical.fasta`) ∪ the file's **439 unique** sequences,
  deduped by md5. 168 file sequences are md5-identical to a v1 node (inherit it); **271** are
  new nodes to classify.
- **Align**: `usearch11 v11.0.667 -allpairs_local`, permissive (`-acceptall`), **both
  orientations** (B3), run in a `linux/amd64` Docker container (binary is a Linux ELF; will not
  run natively on arm64 macOS).
- **Post-process** (`v2/step23_graph.py`, unchanged — carries the B1/B2/B3 fixes): best-scoring
  HSP per pair by bits (B1) → e-value renormalized to the 213-node search space
  (scale 0.4436, B2) → keep ≥30% id AND e<1e−5 → single-linkage components → merge-aware
  canonical IDs (D4).

## Validation gate — PASS

The v1-induced subgraph of the 476-node graph = **42 components**, identical to the corrected
Step 0 reference. The only v1-internal merge is the documented single-edge `1↔35` boundary
merge (30.6% id / e=2.96e−6). The reference frame is intact; assignments are trustworthy
relative to the paper's seed characterization.

## Result — 47 components

**446 file rows / 439 unique sequences classified:**

| outcome | unique seqs | rows | meaning |
|---|---:|---:|---|
| existing_v1 | 168 | 174 | sequence is already a v1 seed (md5-identical) |
| join | 64 | 64 | new sequence joins one existing component |
| merge | 200 | 201 | new sequence lands in a merged component (mostly M1) |
| novel | 7 | 7 | new sequence forms a brand-new family |

Components: **37 inherited + 2 merged + 1 split + 7 novel = 47**.

### M1 — the A/B-hydrolase megamerge (282 nodes)
Absorbs v1 components **1, 20, 35** (84 v1 + 198 new), all CATH `3.40.50.1820`. **198 of the
271 new file sequences (73%)** chain into this one component — single-linkage across the
promiscuous A/B-hydrolase fold, the same behavior seen in the v2 run (there: M1 = 1,20,35).

### M27 — new small merge (5 nodes)
Bridges v1 components **27 + 30** (3 v1 + 2 new), CATH `3.40.50.1820`. Not present in the v2
run — introduced by the file's new sequences.

### Growth into existing components (join)
Largest: comp **9** (6→48, +42 new; CATH 3.60.70.12), then **16** (+6), **23** (+3), **21**
(+3), **10/11** (+2 each).

## Caveats
- The file carries **no accessions** — new-node canonical IDs resolve on `enzyme_name` (77 are
  bare numeric IDs). Provenance is weaker than the accession-anchored v1/v2 runs.
- Step 4 (per-component HMM domain models) not built — HMMER is not installed here.
- One short sequence (28 aa) is retained as-is; no fragment filter applied (the v2 run found a
  fragment filter is needed before an overlay becomes canonical).
- 42-component target is conditional on the v1 reference matching the paper's 2024-12-19 pull.
